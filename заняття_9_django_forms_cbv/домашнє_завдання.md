# Домашнє завдання

## Мета

Закріпити мінімальний CBV, стандартний Django login/logout і звичайну форму у власному персональному проєкті.

## Завдання

1. Зробити, щоб сторінка `about` або інша проста статична сторінка працювала через `TemplateView.as_view()`.
2. Зробити, щоб `/login/` відкривав форму входу.
3. Зробити, щоб logout працював через `POST`.
4. У navbar показати:
   - login link для анонімного користувача;
   - username і logout для авторизованого користувача.
5. Додати або перевірити одну сторінку, доступну тільки після login: наприклад, `/profile/`, `/dashboard/`, `/my-items/` або іншу сторінку з логіки персонального проєкту.
6. Додати або перевірити одну звичайну Django-форму для сценарію персонального проєкту:
   - створення заявки;
   - створення відгуку;
   - надсилання повідомлення;
   - фільтр або пошукова форма;
   - інший доречний сценарій.
7. Перевірити валідацію форми:
   - занадто коротке значення дає помилку;
   - некоректне значення з предметної області проєкту дає помилку;
   - коректне значення показує сторінку підтвердження або успішно повертає користувача до потрібної сторінки.
