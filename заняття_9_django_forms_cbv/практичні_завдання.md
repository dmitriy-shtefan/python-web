# Практичні завдання


## Завдання 1. Простий CBV

1. У `courses/views.py` створіть `AboutView` через `TemplateView`.
2. У `courses/urls.py` підключіть його через `AboutView.as_view()`.
3. Перевірте, що сторінка `/about/` відкривається.
4. Поясніть у коментарі до себе: що робить `as_view()`.

## Завдання 2. Protected page

1. Створіть view `my_courses` за аналогією з courses list (поки що будемо показувати всі курси).
2. Закрийте його через `@login_required`.
3. Додайте URL `my-courses/`.
4. Створіть шаблон `courses/my_courses.html`.
5. У includes навігації додайте посилання на `/my-courses/`.
6. Перевірте, що anonymous перенаправляється на login.

## Перевірка

- `/about/` працює через CBV.
- `/login/` відкривається.
- logout працює через `POST`.
- `/my-courses/` недоступна без login.
- `/ask-teacher/` показує form.
