# Практичні завдання

## Завдання 1.

1. Для моделі Module з проєкту edu_platform.
2. Створити serializer.
3. Додати GET endpoint (api-view) для списку об'єктів.
4. Перевірити JSON-відповідь у браузері.

## Завдання 2.

1. Для моделі Enrollment з проєкту edu_platform.
2. Створити serializer.
3. Додати read-only endpoint для списку об'єктів.
4. Показати 2 повʼязані моделі (Course, User) вкладено через окремі serializer-и (без many=True).
5. Перевірити JSON-відповідь у браузері.

Так можна додати імпорт класу User в serializers.py:
```python
from django.contrib.auth import get_user_model

User = get_user_model()
```
