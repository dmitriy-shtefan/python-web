# Домашнє завдання

## Мета

Закріпити базову роботу з DRF на невеликому навчальному прикладі без обов'язкової прив'язки до персонального проєкту.

## Завдання

1. Взяти демо-проєкт із заняття або персональний проєкт.
2. Підключити Django REST Framework.
3. Створити один serializer.
4. Реалізувати один read-only API-ендпоінт, який повертає список об'єктів у JSON.
5. Зробити короткий приклад відповіді API.

## Що здати

- Код serializer і API view.
- URL API-ендпоінта.
- Короткий приклад JSON-відповіді або скріншот перевірки.

## Обсяг

Домашнє завдання має бути невеликим: один serializer і один endpoint достатньо.

Якщо бракує часу перед іспитом, пріоритетом є доздача попередніх домашніх завдань і доведення персонального проєкту до прийнятного стану. 
Використання DRF у персональному проєкті є опціональним.

## На що звернути увагу

- Не потрібно додавати автентифікацію, permissions, pagination або складний CRUD.
- Відповідь API має бути структурованою й читабельною.
- Код має запускатися без помилок.
