# Практичні завдання

## Завдання 1. Додати CRUD для модулів курсу

Реалізуйте міні-цикл для `Module`, але тільки всередині курсів поточного викладача.

### 1. Форма

У `courses/forms/module.py` створіть `ModuleForm`. Додайте `ModuleForm` в `__init__.py`

У форму додайте тільки поля, які викладач може редагувати:

- `name`;
- `description`;
- `order` (додайте, якщо немає в моделі);
- `number_of_classes`;

Поле `course` не додавайте у форму. Курс має визначатися з URL і перевірятися у view.

### 2. Create

Створіть view для додавання модуля до конкретного курсу:

- URL має містити `course_id`;
- view доступна тільки авторизованому викладачу;
- курс треба отримати через `get_object_or_404(Course, id=course_id, teacher=request.user)`;
- після `form.is_valid()` використайте `form.save(commit=False)`;
- перед `module.save()` встановіть `module.course = course`;
- після успішного створення поверніть викладача на teacher dashboard.

Приклад URL:

```python
path(
    "teacher/courses/<int:course_id>/modules/create/",
    views.module_create,
    name="module_create",
)
```

### 3. Update

Створіть view для редагування модуля:

- URL має містити `module_id`;
- view доступна тільки авторизованому викладачу;
- модуль треба отримати через зв'язок з курсом поточного викладача:

```python
module = get_object_or_404(
    Module,
    id=module_id,
    course__teacher=request.user,
)
```

- у форму передайте `instance=module`;
- після успішного збереження поверніть викладача на teacher dashboard.

### 4. Delete

Створіть view для видалення модуля:

- URL має містити `module_id`;
- модуль треба отримати через `course__teacher=request.user`;
- сторінка `GET` показує підтвердження;
- реальне видалення виконується тільки після `POST`;
- після видалення поверніть викладача на teacher dashboard.

### 5. Шаблони й посилання

Додайте:

- шаблон форми модуля, наприклад `courses/module_form.html`;
- шаблон підтвердження видалення, наприклад `courses/module_confirm_delete.html`;
- на teacher dashboard посилання `Додати модуль` біля кожного курсу;
- біля кожного модуля посилання `Редагувати` і `Видалити`.

Якщо dashboard ще не показує модулі курсу, додайте вкладений список:

```django
{% for module in course.modules.all %}
    <li>
        {{ module.order }}. {{ module.name }}
        <a href="{% url 'module_update' module.id %}">Редагувати</a>
        <a href="{% url 'module_delete' module.id %}">Видалити</a>
    </li>
{% empty %}
    <li>У курсі ще немає модулів.</li>
{% endfor %}
```

## Додаткове завдання

Додайте коротке повідомлення через Django messages після створення, редагування або видалення модуля:

- `Модуль створено.`;
- `Модуль оновлено.`;
- `Модуль видалено.`.
- 

Очікуваний результат:

- `teacher1` може створювати модулі тільки у своїх курсах;
- `teacher1` може редагувати тільки модулі своїх курсів;
- `teacher1` може видаляти тільки модулі своїх курсів;
- поле `course` не доступне у формі;
- чужий `course_id` або `module_id` не відкриває форму редагування чи видалення;
- студент і anonymous не мають доступу до module CRUD;
- student-сценарій `/enroll/` і `/my-courses/` після змін не зламався.
