# Практичні завдання

## Завдання 1.

1. У FastAPI-проєкті додати endpoint `GET /items/{item_id}`.
2. Прийняти `item_id` як path-параметр.
3. Повернути JSON з 2-4 полями.
4. Перевірити endpoint у `/docs`.
5. Пояснити, де в цьому endpoint path-параметр.

## Завдання 2.

1. У FastAPI-проєкті додати endpoint `GET /search`.
2. Прийняти хоча б один query-параметр, наприклад `q` або `level`.
3. Повернути JSON з результатом пошуку або списком знайдених об'єктів.
4. Перевірити endpoint у `/docs`.
5. Пояснити, чим query-параметр відрізняється від path-параметра.

Додаткове завдання для тих, хто швидко впорався:

```python
@app.get("/stats")
def get_stats():
    return {
        "total": len(courses),
        "levels": ["beginner", "intermediate"],
    }
```
