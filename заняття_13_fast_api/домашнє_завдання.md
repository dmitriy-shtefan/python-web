# Домашнє завдання

## Мета

Закріпити базовий синтаксис FastAPI на невеликому самостійному прикладі без обов'язкової прив'язки до персонального проєкту.

## Завдання

1. Створити один файл `main.py` з мінімальним FastAPI-застосунком.
2. Додати 2 endpoint:
   - `GET /items` повертає список з 3-5 об'єктів;
   - `GET /items/{item_id}` повертає один об'єкт або повідомлення, що його не знайдено.
3. Перевірити endpoints через `/docs`.

## Що здати

- Файл `main.py`.
- Скріншот `/docs` або приклад JSON-відповіді.

## На що звернути увагу

- Не потрібно підключати базу даних.
- Не потрібно робити повний CRUD.
- Відповіді мають бути валідним JSON.
- Код має запускатися через `uvicorn main:app --reload`.
