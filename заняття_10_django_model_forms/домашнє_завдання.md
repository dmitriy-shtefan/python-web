# Домашнє завдання

## Мета

Закріпити `ModelForm`, зв'язок запису з поточним користувачем, `save(commit=False)` і сторінку "Мої записи" у власному персональному проєкті.

## Обов'язковий мінімум

1. Зробити, щоб `/login/` відкривав форму входу.
2. Зробити, щоб logout працював через `POST`.
3. У navbar показати:
   - login link для анонімного користувача;
   - username і logout для авторизованого користувача.
4. Додати або перевірити одну сторінку, доступну тільки після login: наприклад, `/profile/`, `/dashboard/`, `/my-items/` або іншу сторінку з логіки персонального проєкту.

Додаткове завдання:

1. Обрати у персональному проєкті сценарій, де користувач створює запис, пов'язаний з іншою сутністю:
   - бронювання події або послуги;
   - заявка на товар, майстра, консультацію або участь;
   - замовлення;
   - додавання елемента до особистого списку;
   - інший сценарій з логіки проєкту.
2. Переконатися, що модель такого запису має:
   - поле користувача, наприклад `user`, `owner`, `client`, `patient` або іншу доречну назву;
   - зв'язок з основною сутністю проєкту;
   - дату створення;
   - статус або прапорець активності.
3. Переконатися, що ця модель видна в admin.
4. Створити `ModelForm`, у якій користувач не може вручну обрати власника запису.
5. Перевірити сторінку створення запису:
   - anonymous перенаправляється на login;
   - logged-in user може створити запис.
6. Перевірити сторінку "Мої записи":
   - перший користувач бачить тільки свої записи;
   - другий користувач не бачить записи першого користувача.
7. Перевірити, що повторний запис на той самий об'єкт, якщо він не має сенсу у вашому проєкті, показує помилку.
